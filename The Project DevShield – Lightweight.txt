The Project: "DevShield" – Lightweight API Gateway & Rate Limiter DashboardWhat is DevShield?An API Reverse Proxy & Security Middleware. It sits between client applications and downstream microservices to:Intercept incoming HTTP requests.Enforce configurable Rate Limiting (using a Redis Token Bucket / Sliding Window algorithm).Monitor latency and request analytics in real time.Block malicious or excessive traffic with 429 Too Many Requests.Why this makes a world-class Portfolio Project:Systems & Networking: Shows you understand HTTP proxies, request headers, status codes, and network latency.Database & Caching: Uses Redis for fast sub-millisecond memory lookups.Antigravity Synergy: Since Antigravity supports MCP (Model Context Protocol) servers for databases/Git and can spin up parallel subagents, we can dispatch tasks synchronously across the backend engine, Redis store, and dashboard UI.
